# Privacy-aware Data Science offerings

[Course portal](../README.md)

Each offering describes one institution's delivery of the shared PaDS course.
Names follow the other TULIP Lab courses: institution, course name, then year.
Course-home links use the shorter institution-and-year label.

The directory pattern is `offerings/<institution>/<unit>/<year>/` for a single
offering in that year. Audience and teaching allocation are recorded on the
offering page rather than encoded in the path.
